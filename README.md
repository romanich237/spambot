# Telegram бот‑автоответчик: сообщения админу + “Подарок” (Stars)

Бот работает как **автоответчик‑курьер**: пользователь пишет боту — бот доставляет сообщение админу, а админ может ответить пользователю “через” бота.

Также в боте есть донат через **Telegram Stars** (официальная валюта Telegram) в виде платежа **«Подарок»** с описанием **«Анонимный подарок»**.

## Возможности

- **Автоответчик**
  - Пользователь отправляет любое сообщение (текст/фото/видео/голос/файл) — бот **сразу копирует** это сообщение администратору.
  - Пользователь получает подтверждение “принято”.

- **Карточка “от кого” для админа**
  - Перед каждым сообщением пользователя админу приходит карточка с:
    - **кликабельным именем** (ссылка на профиль)
    - **username**
    - **user_id**
  - В карточке есть кнопки: **Ответить**, **Забанить/Разбанить**, **Написать** (открыть профиль).

- **Ответы админа (переработано, надёжно)**
  - **Вариант А (рекомендуется)**: нажать в карточке кнопку **Ответить** → бот отправит админу “подсказку” с ForceReply → админ отвечает **reply** на подсказку → бот доставляет ответ пользователю.
  - **Вариант Б**: админ отвечает **reply** на скопированное ботом сообщение пользователя → бот доставляет ответ пользователю.

- **Бан‑лист (с сохранением)**
  - Забаненный пользователь не сможет отправлять сообщения в автоответчик.
  - Бан‑лист сохраняется в `bot_data.json` рядом с `main.py`.
  - Команды админа:
    - `/bans` — список банов
    - `/ban <user_id>` — забанить
    - `/unban <user_id>` — разбанить

- **Подарок (Telegram Stars / XTR)**
  - Кнопка **⭐ Задонатить**: можно выбрать сумму кнопкой или **написать число звёзд сообщением**.
  - Команда (без кнопок): `/gift <звёзды>` (пример: `/gift 123`)
  - Бот **не засоряет чат** лишними подтверждениями — Telegram показывает инвойс сам.

## Установка

### 1) Зависимости

```bash
pip install -r requirements.txt
```

### 2) Конфиг

Открой `config.py` и заполни:

- **`BOT_TOKEN`** — токен бота из @BotFather
- **`ADMIN_ID`** — твой Telegram `user_id` (кому будут приходить сообщения)

### 3) Запуск

```bash
python3 main.py
```

## Как пользоваться

### Для пользователя

- Просто пиши боту — он работает как автоответчик.
- Для подарка:
  - нажми **⭐ Задонатить** и отправь число звёзд сообщением, или
  - набери `/gift 123`.

### Для администратора

- В чате с ботом ты будешь получать карточку “от кого” + сообщение пользователя.
- Чтобы ответить:
  - нажми **Ответить** в карточке и ответь **reply** на подсказку, или
  - ответь **reply** на скопированное сообщение пользователя.

## Файлы проекта

- `main.py` — логика бота
- `config.py` — токен и ID администратора
- `requirements.txt` — зависимости
- `bot_data.json` — сохраняемый бан‑лист (создаётся автоматически)

## Примечания

- Telegram Stars используют валюту **`XTR`**.
- В этом проекте **логирование отключено** (никаких `logging`).
