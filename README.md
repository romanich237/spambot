# Telegram бот: пересылка сообщений админу + донаты Stars

## Что умеет

- **✍️ Написать**: пользователь отправляет сообщение → бот копирует его админу (ID берётся из `config.py`).
- **Ответ админа**: админ отвечает **reply** на скопированное сообщение → бот доставляет ответ пользователю.
- **⭐ Задонатить**: донат через **Telegram Stars** (`XTR`) с фиксированными суммами и “своей”.

## Настройка

1) Установи зависимости:

```bash
pip install -r requirements.txt
```

2) Заполни `config.py`:

- `BOT_TOKEN` — токен из @BotFather
- `ADMIN_ID` — твой Telegram user_id

3) Запусти:

```bash
python3 main.py
```

## Заметка про Stars

Платёжные инвойсы для Stars используют валюту `XTR`.
